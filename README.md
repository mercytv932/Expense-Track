Expense Tracker 💰

A simple expense tracker built with HTML, CSS, and JavaScript to practice arrays, rendering, totals, deletion, and localStorage.

Features
Add expense name and amount
Display expenses dynamically
Delete individual expenses
Calculate total expenses
Save expenses with localStorage
Restore saved expenses after page refresh
Clear input fields after adding
Responsive modern UI
Technologies Used
HTML5
CSS3
JavaScript
localStorage
What I Learned
Using arrays as app memory
Creating expense objects
Rendering data from an array
Using forEach
Deleting items with filter
Calculating totals with loops
Converting input strings to numbers with Number()
Saving data using JSON.stringify
Loading data using JSON.parse
Updating UI after data changes
